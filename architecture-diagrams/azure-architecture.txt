ADDITIONAL AZURE SERVICES (not shown above for clarity):
=========================================================

┌─────────────────────────────────────────────────────────────────┐
│                    AZURE KEY VAULT                               │
│  • JWT signing keys                                             │
│  • Database connection strings                                  │
│  • API keys for external services                               │
│  • TLS certificates                                             │
│  • Accessed by pods via Managed Identity (no passwords in code) │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│              AZURE MONITOR + LOG ANALYTICS                       │
│  • Aggregates logs from all pods                                │
│  • Metrics: CPU, memory, request latency, error rates           │
│  • Alerts: notify team when error rate spikes                   │
│  • Application Insights: distributed tracing across services    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│              AZURE CONTAINER REGISTRY (ACR)                      │
│  • Private Docker image registry                                │
│  • Stores versioned images: my-app:1.0, my-app:1.1, my-app:2.0 │
│  • AKS pulls images from ACR using Managed Identity             │
│  • Image scanning: detects vulnerabilities in images            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│              AZURE ACTIVE DIRECTORY (AAD)                        │
│  • Identity provider for the application                        │
│  • Issues OAuth2/OIDC tokens (used as JWTs)                     │
│  • Manages Managed Identities for pods (no secrets needed)      │
│  • Controls RBAC for Azure resources                            │
└─────────────────────────────────────────────────────────────────┘

CI/CD PIPELINE (How code gets to production):
=============================================

Developer's laptop
      │
      │  git push
      ▼
GitHub / Azure DevOps Repository
      │
      │  Triggers CI pipeline
      ▼
Azure DevOps / GitHub Actions Pipeline
      │
      ├── Run unit tests (JUnit, Jest)
      ├── Run integration tests
      ├── Build Docker images
      ├── Push images to Azure Container Registry
      └── Deploy to AKS (kubectl apply / Helm upgrade)
                  │
                  ▼
           AKS performs rolling update
           (zero downtime deployment)
