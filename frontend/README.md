# Frontend

This directory contains the React-based frontend application.

## Structure

```
frontend/
├── src/          # Application source code
├── public/       # Static assets
└── package.json  # Dependencies and scripts
```

## Setup

```bash
cd frontend
npm install
```

## Run

```bash
npm start
```

The app will be available at `http://localhost:3000`.

## Build

```bash
npm run build
```
